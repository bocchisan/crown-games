# crown-games/e2e-fixtures

Тестовые фикстуры, общие для всех игровых канистр. **Не компоненты системы** — каждая существует
только затем, чтобы дотянуться до пути, недостижимого из теста напрямую.

| Фикстура | Зачем |
|---|---|
| `relay-proxy` | ingress не умеет прикреплять циклы, поэтому инварианты оплаченного pull'а (`Underpaid`, «нет вердикта» без списания, `WrongTarget`) достижимы только из inter-canister вызова. Прокси форвардит сырые предзакодированные аргументы любому методу — одна фикстура на все игры. |
| `mock-sol-rpc` | SOL RPC-канистра живёт на mainnet IC и с локальной реплики недостижима. Мок встаёт на её пиннутый principal и отдаёт синтетическую `create_escrow`-транзакцию; байты внутри настоящие, поэтому индекс парсит и распознаёт их ровно как в проде. |

Обе — отдельные крейты с пустым `[workspace]`, чтобы собираться по манифесту, не втягиваясь в
воркспейс игры.

**Почему здесь, а не в каждой игре.** До `P7.6` лежало по копии в `<игра>/e2e/`: шесть крейтов вместо
двух, причём `mock-sol-rpc` побайтово одинаков во всех трёх, а `relay-proxy` различался одной строкой
комментария. Фикстура не про игру — она про то, чего не умеет тестовая среда, а этого во всех трёх
играх поровну.

Живые devnet-драйверы (`<игра>/e2e/<t5|a5|f5>`) остаются у своих игр: они прогоняют **её** сценарий.
