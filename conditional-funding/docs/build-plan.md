DoD не-отрицательности (`cost.md §6`): F2 — `create_collection`/`ready`/`cancel` без пруфа рождения не
растят память; F3 — нулевой голос не доходит до `update`; F4 — одна подпись на сбор, переиспользуемая
всеми N эскроу **из хранилища** (второй эскроу не платит за уже существующую подпись) — это и делает
амортизацию `s/N` фактом, а не возможностью.

² F2: `create_collection` (получатель-подписант) пересчитывает `collection_id` из предъявленных полей + снимка конфига (`voting_period`/`approval_threshold`/`quorum_weight`) и сверяет с подписанным `collection`; деривует резолвер `key([collection_id])`. **С пруфом рождения** первого вклада — верифицирует его на деривуемом адресе эскроу (BLS-сертификат индекса → корень → свидетель → рождение; крипта общая — `crown-games-common`) и материализует `Funding`, фиксируя `created_at`. **Без пруфа** — эхо деривации, ноль записи (DoD не-негативности). `ready`/`recipient_cancel` — самоподписаны, не материализуют (`NotFound` на неоматериализованном). Слот→время: линейный якорь (`slot_ms`/`genesis_slot`/`genesis_unix` в `config/`, изолирован в `config::slot_to_created_at`; devnet-якорь замерен на F5, mainnet — плейсхолдер до P8, фриз-гейт `genesis_unix≠0`). Общая крипта вынесена в `crown-games-common` (единый источник BLS/threshold-деривации; `conditional-tasks` репойнтнут, тесты держат). `vote`/`request_signature` — типизированные заглушки до F3/F4. 50 тестов (logic 14 + канистра 17 + common 19), clippy strict/fmt/wasm/.did чисто.

³ F3: `vote` — вес = репутация голосующего к получателю сбора, доказывается свидетелем книги против сертифицированного корня индекса (`birth::reputation_from_witness`, крипта общая); `choice ∈ {done,not_done}`; запись через `step` (только в `Voting`, порог `MIN_VOTE_WEIGHT`, дедуп `(collection_id, voter)`), кэп `V_MAX=500`. Валидность (подпись+таргет+вес ≥ порога) отбивается бесплатно в `inspect_message` до исполнения (нулевой/невалидный не доходит до `update`). Дедуп/порог/кэп покрыты тестами `state.rs`; рантайм-гейт `inspect_message` — на F5.

⁴ F4: `request_signature(chain, collection)` — оплаченный pull (фронтит релеер за `SIGN_PRICE`): проверка оплаты (`msg_cycles_available ≥ SIGN_PRICE` → иначе `Underpaid`) и таргета до `sign_with_schnorr`; неготовый вердикт → `NotDecided` **без списания**. `verdict(collection_id)` → `outcome` (settle=0/refund=1); списание принимается **только** перед подписью. **Одна** подпись `key([collection_id])` над `verdict_message(DOMAIN, program_id, outcome)` переиспользуется всеми N эскроу (все деривуют этот резолвер) **и хранится после первой выдачи** — эскроу со второго по N-й получают её бесплатно, чем амортизация `s/N` и становится фактом — это и есть атомарность: один исход на весь сбор, без Merkle-корня/пути. `verdict_message` общий (форма two-outcome). Реальная threshold-подпись + сеть — на F5.

¹ F1: `logic/` zero-dep — машина `Funding→Voting{started_at}→Decided` (окна: `[created_at, created_at+duration]` от slot→время рождения; `[started_at, started_at+voting_period]`; границы строго `>=`; время до действия; overflow не двигает состояние). Вердикт **с кворумом**: `turnout=yes+no ≥ quorum_weight` **и** `yes·10000 > approval_threshold·turnout` (строго) → settle; ничья/недобор/пусто/overflow → refund. 14 тестов (property: settle-iff-rule; unit: границы окон, silence→refund, дедуп/порог, decided-absorbing, overflow). clippy strict/fmt чисто.

⁵ F4.5: расщеплённое доверие к индексу — как у эталона. Добавлены `push_root(cert)` (оплаченный
пуш за `ROOT_PRICE`, кеш `ROOTS` глубины `ROOT_CACHE = 4`, повторный пуш освежает позицию и не растит
кеш), вариант `RootPushed`, `root_price` в `config/*.toml`. `admit_create_collection` и `voter_weight` больше **не** зовут
`birth::certified_root` — реконструируют свидетеля против кешированного корня (обход хеш-дерева,
O(log n)); `cert` ушёл из wire-формата обоих. Причина: две BLS-пары не влезают в 200M инструкций
`inspect_message`, то есть **валидная** материализация не проходила бы вовсе. Закреплено гейтом CI
(«BLS only on the paid push_root»: ровно одно вхождение, внутри `push_root`). **+4 теста:**
`endpoint_e2e` — неоплаченный `push_root` не делает работы, оплаченный с кривым сертификатом отбит
(оплата не возвращается), `create_collection` со свидетелем без кеша корней отбит на границе;
**`full_e2e`** (новый файл + фикстура `e2e/mock-sol-rpc`) — мок SOL RPC → `index.ingest` →
сертифицированное рождение → `push_root` → `create_collection` **прямым ingress** → `Materialized` →
`recipient_cancel` → `request_signature` → **реальная 64-байтная Ed25519 threshold-подпись** под
`key([collection_id])`, проходящая `verify_strict` против резолвера; повтор отдаётся из хранилища
**бесплатно** (нулевые циклы) и `get_signature` даёт те же байты — этим амортизация `s/N` из
возможности становится фактом. **48 тестов** (logic 19 + канистра 20 + pocket-ic 9), clippy
strict/fmt/wasm/.did чисто.

⁶ F5: живой прогон **выполнен** на Solana devnet против локального PocketIC-стека (индекс + мок SOL RPC
+ релей-прокси + funding на `key_1`); драйвер — `e2e/f5`. Прогнаны **два** сбора по `N=2` вклада, и
оба исхода — на настоящих деньгах. Реальный `splitter.donate` покупает голосующему вес по книге; четыре
реальных `create_escrow` по 1 тест-USDC (у каждого сбора — один резолвер на оба вклада); все четыре
рождения свёрнуты индексом; оплаченный `push_root` → два `create_collection` **прямым ingress** → сбор A:
`ready` → **голос** весом 0.5 USDC (кворум 0.15) → окно закрылось → `Decided{Settle}`; сбор B:
`recipient_cancel` → `Decided{Refund}`. По одному оплаченному `request_signature` на сбор, **повтор
бесплатен** (ноль циклов, те же байты) и `get_signature` отдаёт их же — этим амортизация `s/N`
становится фактом. На devnet **одна** подпись отклеймила **оба** эскроу своего сбора: A → получателю
`2·net`, комиссии `2·fee`; B → донору `2·gross`; все четыре vault закрыты. Сеттлменты свёрнуты обратно —
репутация на **доноре**, на адресах эскроу ноль.

Прогон вскрыл две вещи, которые прятал кэш. **Первая — в конфиге:** профиль живого прогона не имел
`min_gross`, которого требует `build.rs`; пересборка wasm пропускалась, если файл уже лежал, поэтому
гейт ни разу не сработал. Теперь `full_e2e` пересобирает wasm всегда (байты зависят от `config/`, а
устаревший артефакт молча расходится с ид, которые считает тест). **Вторая — про две разные
принадлежности:** игре предъявляется рождение только **первого** вклада (остальные — члены по
деривации, в этом весь смысл одной подписи), но **книга поштучна**: атрибуция читает `escrow → donor`
из рождений (`00 §4`), и сеттлмент эскроу, которого индекс не видел, засчитывается адресу эскроу, а не
человеку. Поэтому впись рождения нужна на **каждый** вклад, чью репутацию собираются предъявлять —
покупает её тот, кому она нужна (`cost.md §8`).

Побочно закрыты те же два плейсхолдера, что и в аукционе: якорь slot→unix (замерен на devnet) и
devnet-кошелёк комиссии. Непокрытый шов тот же — многопровайдерный RPC-консенсус (`F6`).
