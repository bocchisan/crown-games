# subscription — CLAUDE.md

Использование формы `stream`: один донор предоплачивает поток, выпуск **по расписанию** (не по подписи).
Не крауд, голосования нет — 1:1 донор↔получатель. Резолвера, threshold-ключа и канистры нет.

Контракт игр — `crown-spec/docs/games-harness.md` (к подписке применим лишь §1). Строгость/глоссарий —
`crown-spec/CLAUDE.md`. Спека — `docs/spec.md`; план — `docs/build-plan.md`.

Специфика:
- **Выпуск по расписанию, permissionless** (`release(k)` при `now ≥ t0+k·period`) — детерминированное
  условие, threshold-подпись не нужна. Дёшево: break-even ~$0.20/выпуск (без `s`).
- **Отмена — подпись донора** (ончейн, против поля `donor`); `refund()` без подписи по просрочке
  (`RELEASE_MARGIN`). Выплата — **через сплиттер** (единая точка).
- Канистры/резолвера/оплаченного pull нет: подписка — это форма `stream`, а не резолвер-игра.
- Ончейн-детали формы `stream` — **канон здесь**, в `docs/spec.md`; `crown-factory/docs/spec.md`
  держит контракт формы и ссылается сюда, не дублируя.
